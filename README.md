# harmak-tickets-lab
Laboratorio de tickets correctivos e integración Odoo

## Estructura

- [`odoo-lab/`](odoo-lab/README.md): entorno local de Odoo 17 + PostgreSQL 15 con Docker Compose (solo datos de prueba).
- `.devcontainer/`: configuración de GitHub Codespaces. Al crear un Codespace el laboratorio
  se prepara, arranca y verifica automáticamente; Odoo queda en el puerto privado 8069.
